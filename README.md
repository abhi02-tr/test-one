# 💗 A Cute Apology Website for Siaa

A personal, sweet, romantic, and interactive surprise website created by **Abhi** for **Siaa**.

![Hero Teddy Bear](public/images/bear_with_heart.jpg)

---

## 🧸 About This Project

This website was built to apologize in a gentle, playful, and heartwarming way for not giving Siaa enough hugs today, promising plenty of hug compensations, and inviting her on a cozy date tomorrow!

### ✨ Key Features

1. **Section A: Welcome / Apology Hero**
   - Soft pastel aesthetic with blush pink, warm cream, and lavender.
   - Cute 3D kawaii teddy bear gently holding a glowing heart.
   - Eyebrow badge: `A LITTLE NOTE FOR YOU 💌`
   - Heading: `I'm Sorry, Siaa 🥹💗`
   - Personal text acknowledging the hug shortage.
   - Interactive `Open Your Little Surprise 💌` button with smooth scrolling.

2. **Section B: A Proper Apology**
   - Romantic letter card with love letter illustration and wax heart seal.
   - Sincere, casual, personal apology message from Abhi.
   - Playful caption: `"Hug shortage: Abhi's fault. Hug compensation: pending... 😂"`
   - Interactive **Siaa's Mood & Forgiveness Meter** with playful dynamic reactions.

3. **Section C: Virtual Hug Interaction**
   - Visual of two fluffy teddy bears warmly cuddling.
   - Interactive `Send Me a Hug 🤗` button.
   - Squeeze animation on the bears and floating heart bursts / confetti.
   - Hug counter with sweet progressive unlock messages.
   - Synthesized warm acoustic chord using the Web Audio API.

4. **Section D: The Hug Promise**
   - Heading: `My Official Hug Compensation Plan 📋😂`
   - Three interactive cards:
     - **Extra Hugs**
     - **Longer Hugs**
     - **Unlimited Cuteness**
   - Tap-to-claim mechanism with `Claimed by Siaa ✔️` stamps and confetti.
   - Official Hug Warranty & Guarantee badge.

5. **Section E: Tomorrow's Date Invitation**
   - Heading: `One More Question for Tomorrow... 🌸`
   - The question: *"Would you like to go on a date with me tomorrow, Siaa? ☕✨"*
   - Playful buttons:
     - `Yes, absolutely! 🥰` (triggers celebration confetti and romantic chime)
     - `Hmm, let me think... 😜` (playfully cycles through funny persuasive phrases)
   - Date vibe selector (Cozy Cafe, Sunset Stroll, Dessert Crawl, Surprise Me).
   - Optional special note/demand box for Siaa.
   - Interactive **Golden Date Pass & Hug Voucher** with one-click copy to share via WhatsApp/Chat.

6. **Audio & Delightful Touches**
   - Floating music player pill in top right to toggle a gentle music-box lullaby (zero external audio file dependencies).
   - Floating ambient hearts, stars, and sparkles drifting in the background.
   - Secret Note easter egg in the footer (`Tap for a Tiny Secret Note 💌`).
   - Accessible, responsive, and honors `prefers-reduced-motion`.

---

## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

3. Build for production:
   ```bash
   npm run build
   ```

4. Lint check:
   ```bash
   npm run lint
   ```
